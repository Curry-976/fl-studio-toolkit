Navigation Générale

Fenêtres, lecture, projet
Espace
Play / Pause
Lance ou met en pause la lecture. Appuyer à nouveau repart depuis la position actuelle.
Return
Lecture depuis le début
Remet le curseur au début du projet et lance la lecture. Indispensable pour les écoutes complètes.
⌘+Z
Annuler (Undo)
Annule la dernière action. Logic dispose d'un historique illimité des modifications.
⌘+⇧+Z
Rétablir (Redo)
Refait une action annulée.
⌘+S
Sauvegarder le projet
Sauvegarde le projet en cours. Logic propose aussi la sauvegarde automatique.
⌘+⇧+S
Enregistrer sous
Crée une copie du projet sous un nouveau nom. Utile pour les versions alternatives.
⌘+N
Nouveau projet
Crée un nouveau projet vierge. Logic te proposera de sauvegarder le projet en cours.
⌘+O
Ouvrir un projet
Ouvre la boîte de dialogue pour charger un fichier .logicx existant.
L
Activer / Désactiver la boucle
Bascule le mode Loop entre les locators gauche et droit. Très utile pendant le mixage.
/
Aller au locator gauche
Déplace la tête de lecture au locator gauche (début de la boucle).
X
Afficher / Masquer le Mixer
Ouvre ou ferme la fenêtre Mixer en bas de l'écran.
E
Ouvrir le Piano Roll
Ouvre l'éditeur Piano Roll pour la région MIDI sélectionnée.
I
Afficher / Masquer l'Inspecteur
Bascule le panneau Inspecteur (gauche) qui affiche les paramètres de la région ou de la piste.
B
Smart Controls
Ouvre les Smart Controls en bas de l'écran — contrôles rapides pour l'instrument ou les effets.
⌘+B
Bounce (Exporter)
Exporte le projet ou les pistes sélectionnées en fichier audio (WAV, AIFF, MP3…).
⌘+K
Fenêtre Raccourcis clavier
Ouvre la fenêtre de gestion des raccourcis clavier pour les personnaliser.

Arrangement

Régions, pistes, édition
⌘+A
Tout sélectionner
Sélectionne toutes les régions de toutes les pistes. Pratique pour déplacer tout l'arrangement.
⌘+C
Copier
Copie les régions sélectionnées dans le presse-papier.
⌘+V
Coller
Colle les régions copiées à la position de la tête de lecture.
⌘+X
Couper
Coupe les régions sélectionnées pour les déplacer ailleurs.
Suppr
Supprimer la région
Efface les régions sélectionnées. Action annulable avec ⌘+Z.
⌘+D
Dupliquer la région
Crée une copie de la région juste après l'originale sur la même piste.
⌘+J
Fusionner les régions (Join)
Fusionne plusieurs régions sélectionnées en une seule sur la même piste.
⌥+Glisser
Copier une région
Maintiens Option et glisse une région pour en créer une copie instantanément.
⌥+/
Muter / Démuter une région
Mute ou démute la région sélectionnée sans la supprimer.
←/→
Nudge (décaler d'une division)
Décale la région d'une division de grille. Très précis pour aligner les éléments.
⇧+←/→
Déplacer d'une mesure
Déplace la région d'une mesure entière vers la gauche ou la droite.
T
Afficher la boîte à outils
Affiche le menu de sélection des outils (Pointeur, Crayon, Ciseau, Gomme, etc.).
⌘+T
Couper la région à la tête de lecture
Coupe toutes les régions sélectionnées à l'emplacement précis de la tête de lecture.
⌘+⇧+D
Dupliquer la piste
Crée une copie complète de la piste sélectionnée avec ses réglages et plugins.

Piano Roll

Édition MIDI & notes
⌘+A
Tout sélectionner
Sélectionne toutes les notes du Piano Roll. Utile avant de transposer ou quantiser en masse.
Q
Quantiser
Quantise les notes sélectionnées selon la valeur de grille active. Raccourci rapide.
⌘+↑
Transposer +1 demi-ton
Monte les notes sélectionnées d'un demi-ton.
⌘+↓
Transposer -1 demi-ton
Descend les notes sélectionnées d'un demi-ton.
⇧+↑
Transposer +1 octave
Monte les notes d'une octave entière (12 demi-tons).
⇧+↓
Transposer -1 octave
Descend les notes d'une octave entière.
←/→
Déplacer la note (Nudge)
Décale les notes sélectionnées d'une division de grille pour affiner le timing.
⌥+Glisser
Copier une note
Option+Glisser une note pour en créer une copie à l'endroit souhaité.
Suppr
Supprimer la note
Efface les notes sélectionnées. Action annulable avec ⌘+Z.
V
Outil Vélocité
Active l'outil Vélocité pour ajuster l'intensité des notes en faisant glisser verticalement.
P
Outil Crayon (Pencil)
Sélectionne l'outil Crayon pour dessiner de nouvelles notes directement dans le Piano Roll.
⌘+F
Adapter la vue à la sélection
Zoome automatiquement pour afficher l'ensemble des notes sélectionnées dans la fenêtre.

Mixer

Pistes, effets, routage
X
Afficher / Masquer le Mixer
Bascule l'affichage de la console de mixage en bas de la fenêtre principale.
⌥+Clic
Réinitialiser un fader à 0 dB
Option+Clic sur un fader ou un knob pour le remettre à sa valeur par défaut.
⌘+Clic
Solo d'une piste
⌘+Clic sur le bouton Solo pour isoler cette piste sans désactiver les autres solos.
M
Muter / Démuter la piste
Active ou désactive le mute sur la piste sélectionnée dans le Mixer.
S
Solo
Active ou désactive le solo sur la piste sélectionnée.
R
Armer l'enregistrement
Active l'armement de la piste sélectionnée pour l'enregistrement (bouton rouge).
⌘+G
Créer un groupe de pistes
Regroupe les pistes sélectionnées pour contrôler leur volume/mute/solo simultanément.
⌘+⌥+C
Copier les réglages du canal
Copie tous les réglages du channel strip (plugins, sends, routing) pour les coller ailleurs.
⌘+⌥+V
Coller les réglages du canal
Colle les réglages copiés sur le channel strip sélectionné.
⌥+M
Démuter toutes les pistes
Retire le mute de toutes les pistes en une seule frappe. Très utile après une session de comparaison.

Enregistrement & Outils

Record, Flex, nouvelles pistes
⌘+R
Lancer l'enregistrement
Lance l'enregistrement sur toutes les pistes armées. Assure-toi d'avoir armé la bonne piste avant.
⌘+⇧+R
Enregistrement avec Punch-in
Lance l'enregistrement avec punch-in automatique entre les locators pour corriger une section.
F
Activer / Désactiver Flex Time
Active le mode Flex Time sur la piste — permet de déplacer des transitoires audio librement.
⇧+F
Activer Flex Pitch
Active le mode Flex Pitch — permet de corriger la hauteur de chaque note d'une prise audio.
⌘+⌥+A
Nouvelle piste Audio
Crée une nouvelle piste Audio immédiatement sans passer par le menu.
⌘+⌥+S
Nouvelle piste Software Instrument
Crée une nouvelle piste MIDI/Software Instrument pour tes synths et samplers.
⌘+U
Bounce in place
Convertit la région ou la piste en fichier audio directement dans le projet. Idéal pour libérer le CPU.
1à9
Sélectionner un outil (1–9)
Les touches 1–9 sélectionnent directement les outils : 1=Pointeur, 2=Crayon, 3=Gomme, 4=Texte, 5=Ciseau, 6=Glue, 7=Solo, 8=Mute, 9=Zoom.
Échap
Revenir au dernier outil
Escape repasse à l'outil précédemment utilisé — pratique pour alterner rapidement entre deux outils.
⌘+L
Boucler la région
Active le mode Loop sur la région sélectionnée — elle se répète automatiquement.
⌘+⇧+A
Désélectionner tout
Retire la sélection de toutes les régions ou notes sans rien supprimer.
⌘+⌥+F
Zoom pour tout afficher
Adapte le zoom horizontal pour afficher tout le projet dans la fenêtre d'arrangement.
