Template & Session

Débutant
Voir un tutoriel
1

Crée un template avec tes Summing Stacks Drums/Mélo/Basse déjà configurés, ta chaîne master et le Gain de calibration. Tu gagnes 10 min à chaque session.

2

Freeze les pistes lourdes (clic droit → Freeze) pour libérer le CPU sans désactiver les plugins. Unfreeze seulement quand tu retouches la piste.

3

Active Low Latency Mode (bouton tortue dans la toolbar) quand tu joues en live avec un clavier MIDI pour éviter la latence de monitoring.

File → Save as Template après avoir configuré ta session idéale. Logic l'affiche dans l'écran de démarrage à chaque nouveau projet.

Drum Machine Designer

Débutant
Voir un tutoriel
1

Ouvre le Step Sequencer via le bouton en haut du DMD pour programmer tes patterns en mode grille, comme un 808-style beatmaker.

2

Chaque pad a son propre canal Mixer — clic sur un pad et ouvre l'Inspector. Tu peux applique EQ, compresseur et automation séparément sur chaque élément.

3

Drag & drop un sample depuis le Finder directement sur un pad pour remplacer le son du kit sans quitter la session.

Humanisation & Groove

Intermédiaire
Voir un tutoriel
1

Functions → Humanize dans le Piano Roll : randomise vélocité et timing légèrement. Règle Velocity ±10 et Time ±5ms pour commencer.

2

Décale la snare de +5ms manuellement dans le Piano Roll. Elle pousse légèrement en arrière et donne du pocket au groove.

3

Velocity aléatoire sur les hi-hats : sélectionne toutes les notes HH → clic droit → Velocity → randomise ±15. Résultat immédiatement plus vivant.

Dans le Step Sequencer, clic droit sur un step → Velocity pour l'ajuster individuellement. Beaucoup plus rapide que le Piano Roll pour les patterns répétitifs.
🎵

Quick Sampler

Débutant
Voir un tutoriel
1

Drag & drop depuis le Finder sur une piste vide — Logic ouvre automatiquement le Quick Sampler avec le sample chargé. Zéro clic inutile.

2

Mode Slice : Logic détecte les transitoires et crée un pad par tranche. Joue les slices depuis le Piano Roll pour chopper un sample rapidement.

3

Smart Tempo (File → Project Settings → Smart Tempo) : importe un sample, Logic ajuste automatiquement son tempo au projet. Fini les calculs de BPM.

Utilise le Sampler (anciennement EXS24) pour les kits complexes avec mapping de vélocité multi-couche. Quick Sampler pour les samples uniques, Sampler pour les instruments complets.
🔊

808 & Sub Bass

Intermédiaire
Voir un tutoriel
1

Quick Sampler en mode Classic : active Tune, joue les notes dans le Piano Roll pour faire glisser le 808 sur la mélodie du beat.

2

Sidechain kick → 808 : insère le Compressor sur le canal 808, active External Side Chain, sélectionne le canal kick. La pompe est naturelle et contrôlée.

3

High-pass à 35Hz sur le 808 pour éviter l'infra-grave qui sature le master sur les petites enceintes et les téléphones.

Flex Time

Intermédiaire
Voir un tutoriel
1

Flex Time = quantisation de l'audio. Active le bouton Flex sur la piste → choisis le mode → la waveform se déforme pour s'aligner à la grille MIDI.

2

Mode Rhythmic pour les drums et percussions, Monophonic pour les lignes de basse et voix. Le mode Slicing découpe l'audio entre les transitoires.

3

Corriger le timing d'un sample live sans le recouper : active Flex, glisse le marqueur de transitoire sur la grille. Non destructif.

Channel EQ & Gain

Intermédiaire
Voir un tutoriel
1

High-pass tout sauf la basse en dessous de 80–120Hz. Active d'abord l'Analyzer pour visualiser ce que tu coupes. Double-clic sur une bande pour taper la fréquence exacte.

2

Gain (premier insert) : normalise chaque piste à environ −6dBFS avant tes plugins. Le channel EQ sonne mieux à un niveau d'entrée cohérent.

3

Dégager les basses-médiums 200–400Hz sur les éléments qui se gênent. C'est là que la "boue" s'accumule dans un mix trap dense.

Le Channel EQ de Logic a un Analyzer stéréo en temps réel — active-le (bouton Analyzer) pour voir la réponse en fréquence pendant la lecture avant de toucher aux bandes.

Logic Remote

Débutant
Voir un tutoriel
1

Logic Remote sur iPad = surface de contrôle gratuite. Installe depuis l'App Store, même WiFi que ton Mac — connexion automatique.

2

Vue Mixer : ajuste les volumes et pans directement depuis l'iPad pendant l'écoute sur enceintes, sans toucher la souris.

Track Stacks & Organisation

Intermédiaire
Guide complet
📁
Folder Stack
Regroupe des pistes en dossier sans créer de bus. Idéal pour réduire la vue — Ctrl+clic sur les pistes voulues → Create Track Stack → Folder.
🔀
Summing Stack
Groupe + bus automatique. Toutes les pistes enfant routent vers une piste mère. Applique EQ, compression et reverb sur le groupe entier.
📍
Marqueurs (K)
Appuie sur K pour afficher la piste marqueurs. Crée des zones Intro / Drop / Verse pour naviguer d'un clic sur un long projet.
⌘G
Grouper des régions
⌘+G fusionne les régions sélectionnées en une seule. Pratique pour regrouper les éléments d'une batterie multi-micros avant de les déplacer.
→

Workflow recommandé : Summing Stack pour Drums, Mélo, Basse, FX · Marqueurs pour les sections · ⌘+G pour grouper les régions du même moment avant de les déplacer dans l'arrangement.
