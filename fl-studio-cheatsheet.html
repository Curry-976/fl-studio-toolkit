Navigation Générale
Fenêtres, lecture, projet
F1
Ouvrir le Manuel / Aide
Ouvre la documentation intégrée de FL Studio. Pratique pour chercher des infos sans quitter l'application.
F5
Afficher / Masquer la Playlist
Bascule la visibilité de la Playlist — la vue principale pour arranger ton morceau.
F6
Ouvrir le Step Sequencer
Accède au Step Sequencer (Beat+Bassline) pour programmer des patterns rythmiques.
F7
Ouvrir le Piano Roll
Ouvre le Piano Roll pour éditer les notes MIDI. Indispensable pour les mélodies et accords.
F8
Ouvrir le Navigateur
Affiche le Browser de fichiers pour accéder à tes samples, presets et plugins rapidement.
F9
Ouvrir le Mixer
Affiche la table de mixage pour gérer les niveaux, effets et routage de chaque piste.
Espace
Play / Pause
Lance ou met en pause la lecture. Appuyer une 2ème fois repart depuis la position actuelle.
Entrée
Play depuis le début
Remet le curseur à zéro et lance la lecture depuis le début du morceau.
Ctrl+Z
Annuler (Undo)
Annule la dernière action. FL Studio possède un historique illimité.
Ctrl+Y
Rétablir (Redo)
Refait une action annulée. Fonctionne aussi avec Ctrl+Shift+Z.
Ctrl+S
Sauvegarder le projet
Sauvegarde le projet en cours. Prends l'habitude de sauvegarder souvent !
Ctrl+Shift+S
Sauvegarder en nouvelle version
Crée une copie numérotée du projet (v1, v2…). Idéal pour garder l'historique.
Ctrl+N
Nouveau projet
Crée un nouveau projet vierge. FL Studio te demandera si tu veux sauvegarder.
Ctrl+O
Ouvrir un projet
Ouvre la boîte de dialogue pour charger un fichier .flp existant.
Ctrl+E
Basculer Mode Pattern / Song
Alterne entre la lecture du Pattern actif et la lecture complète du morceau.
L
Activer / Désactiver la Boucle
Active le mode Loop pour répéter la sélection indéfiniment. Très utile pendant le mixage.
Ctrl+P
Ouvrir le Plugin Picker
Affiche la liste de tes plugins VST/AU pour en charger un rapidement.
Ctrl+R
Exporter / Render
Ouvre la fenêtre d'export pour rendre ton morceau en WAV, MP3 ou FLAC.
Playlist
Arrangement & clips
Ctrl+A
Tout sélectionner
Sélectionne tous les clips de la Playlist. Pratique pour déplacer l'ensemble d'un arrangement.
B
Mode Dessin (Draw)
Active l'outil Dessin pour placer des clips dans la Playlist en cliquant-glissant.
E
Mode Sélection
Passe en mode Sélection pour sélectionner et déplacer les clips existants.
D
Mode Suppression
Active l'outil de suppression : clique sur un clip pour l'effacer immédiatement.
T
Mode Muet
Clique sur un clip pour le muter/démuter sans le supprimer.
Y
Mode Slip (Décalage temporel)
Permet de décaler le contenu d'un clip sans changer ses bornes.
Ctrl+C
Copier
Copie la sélection de clips dans le presse-papier pour la coller ailleurs.
Ctrl+V
Coller
Colle les clips copiés à la position du curseur sur les mêmes pistes.
Ctrl+X
Couper
Coupe les clips sélectionnés pour les déplacer ailleurs dans l'arrangement.
Suppr
Supprimer la sélection
Efface tous les clips sélectionnés. Action annulable avec Ctrl+Z.
Alt+Glisser
Dupliquer un clip
Maintiens Alt et glisse un clip pour en créer une copie. Plus rapide que Copier/Coller.
Ctrl+Alt+G
Grouper les pistes sélectionnées
Regroupe les pistes sous un dossier. Parfait pour organiser drums, synths, etc.
Ctrl+Molette
Zoom horizontal
Ctrl + Molette pour zoomer/dézoomer sur l'axe temporel de la Playlist.
Piano Roll
Édition MIDI & notes
B
Mode Dessin (Draw)
Active l'outil Dessin pour créer de nouvelles notes en cliquant dans le Piano Roll.
E
Mode Sélection
Sélectionne des notes pour les déplacer, redimensionner ou copier.
Q
Quantisation rapide
Quantise instantanément les notes sélectionnées selon la grille active.
Ctrl+Q
Options de Quantisation
Ouvre les réglages de quantisation pour choisir la valeur de grille et l'intensité.
Ctrl+A
Tout sélectionner
Sélectionne toutes les notes du Pattern. Utile avant de transposer ou copier l'ensemble.
Ctrl+↑
Transposer +1 demi-ton
Monte les notes sélectionnées d'un demi-ton.
Ctrl+↓
Transposer -1 demi-ton
Descend les notes sélectionnées d'un demi-ton.
Shift+↑
Transposer +1 octave
Monte les notes d'une octave complète (12 demi-tons).
Shift+↓
Transposer -1 octave
Descend les notes d'une octave complète.
Ctrl+←/→
Déplacer la note (Nudge)
Décale les notes sélectionnées d'une unité de grille pour affiner le timing.
Ctrl+M
Retourner verticalement
Retourne la sélection de notes sur l'axe vertical (miroir mélodique).
Ctrl+G
Fusionner les notes (Glue)
Fusionne les notes sélectionnées contiguës en une seule note longue.
Mixer
Pistes, effets, routage
Ctrl+L
Lier canal → piste Mixer
Connecte le canal sélectionné au Channel Rack à la piste Mixer sélectionnée.
Alt+Clic
Réinitialiser un paramètre
Alt+Clic sur n'importe quel knob ou fader pour le remettre à sa valeur par défaut.
Ctrl+Clic
Saisir une valeur précise
Ouvre un champ de saisie numérique pour entrer une valeur exacte sur un knob.
Molette
Ajustement fin d'un paramètre
Fais défiler la molette sur un knob pour l'ajuster finement.
Clic LED
Muter / Démuter une piste
Clique sur le témoin vert d'une piste Mixer pour la muter.
Ctrl+Clic LED
Solo d'une piste
Ctrl+Clic sur le témoin d'une piste pour l'isoler en solo.
Ctrl+Shift+V
Ajouter un Send (Sidechain)
Configure le routage sidechain entre deux pistes Mixer.
←/→
Naviguer entre les pistes
Les flèches gauche/droite déplacent la sélection entre les pistes du Mixer.
Clic droit
Créer un clip d'automatisation
Clic droit sur n'importe quel paramètre → "Create automation clip".
F2
Renommer la piste
Ouvre le champ de renommage de la piste Mixer sélectionnée.
Inser
Ajouter une piste Mixer
Insère une nouvelle piste vide dans le Mixer.
Step Sequencer
Patterns rythmiques & beats
Ctrl+A
Tout sélectionner
Sélectionne toutes les steps du canal actif dans le Step Sequencer.
Ctrl+C
Copier le pattern
Copie la séquence de steps du canal sélectionné.
Ctrl+V
Coller le pattern
Colle le pattern copié sur le canal actif.
Ctrl+Suppr
Vider le pattern
Efface toutes les steps actives du canal sélectionné en un seul raccourci.
Alt+→
Décaler le pattern à droite
Décale tous les steps d'un cran vers la droite.
Alt+←
Décaler le pattern à gauche
Décale tous les steps d'un cran vers la gauche.
Clic droit
Propriétés d'une step
Clic droit sur un step pour modifier sa vélocité, la note jouée, le panoramique.
Alt+Clic+Glisser
Régler la vélocité
Alt+Clic+Glisser vertical sur un step pour ajuster sa vélocité directement.
↑/↓
Naviguer entre les canaux
Les flèches haut/bas changent le canal actif dans le Step Sequencer.
Clic sur LED
Muter / Démuter un canal
Clique sur le témoin à gauche du nom de canal pour le muter.
Shift+Clic+Glisser
Sélection multiple de steps
Maintiens Shift et glisse sur plusieurs steps pour les activer/désactiver en masse.
Clic droit sur Step
Changer le nombre de steps
Clic droit sur le dernier step → "Step count" pour modifier la longueur du pattern.
